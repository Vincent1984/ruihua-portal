# 报名模板管理系统操作手册（管理员）

## 入口
- 后台左侧导航：报名模板管理
- 页面地址：`/admin/template-management.html`

## 常用操作
- 新建模板：点击“新建模板”，填写模板名称、活动类型、场景描述。
- 可视化编辑：
  - 在字段表中新增字段，支持拖拽排序。
  - 配置字段类型、必填、正则规则、长度限制。
  - 配置页面标题、活动说明、报名须知、背景图、LOGO、颜色方案。
- 实时保存：编辑过程中可点击“实时保存草稿”，系统也会自动定时保存。
- 发布控制：
  - 启用：模板可被活动选择。
  - 禁用：模板不可新建活动使用。
- 版本管理：
  - 每次保存自动生成新版本。
  - 点击“版本”可查看历史并回滚。
- 克隆模板：点击“克隆”快速复制现有模板。
- 删除模板：仅未被活动使用的模板可删除。

## 活动关联
- 在“活动报名管理”创建活动时选择模板。
- 活动报名页会自动读取模板字段与主题配置。

## 数据分析
- 模板统计接口可查看浏览量、提交量、转化率。
- 可导出模板关联活动的报名数据（CSV/XLSX）。
