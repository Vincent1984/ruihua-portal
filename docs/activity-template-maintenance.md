# 报名模板管理维护手册

## 常见问题
- 模板保存失败（400）
  - 检查模板名称、活动类型、字段配置是否完整。
- 模板删除失败
  - 模板已被活动使用，不允许删除；建议禁用模板。
- 报名页字段不显示
  - 检查活动是否绑定了模板，模板状态是否启用。
- 报名提交报“格式不正确”
  - 检查模板字段正则规则是否过严。

## 运营建议
- 生产中优先使用“克隆+微调”方式创建模板。
- 每次重大修改前先克隆，便于快速回滚。

## 安全与合规
- 后台仅通过 Bearer Token 鉴权。
- 报名数据列表默认敏感信息脱敏显示。
- 保持依赖定期升级并执行漏洞扫描。

## 性能维护
- 定期归档历史报名记录，降低查询压力。
- 导出建议按模板和时间范围分批执行。

## 故障排查
- 查看服务日志中的 `ActivityTemplate`、`Activity`、`Registration` 相关错误。
- 检查 MongoDB 索引：
  - `ActivityTemplate.code`
  - `ActivityTemplate(name, activityType)`
  - `Registration(activityId, phone)`
