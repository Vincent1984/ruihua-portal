# 人力资本价值经营成熟度诊断 - 打分逻辑说明

本文档详细说明了"人力资本价值经营成熟度诊断"工具的评分机制、权重分配及结果判定标准。

## 1. 评分概览

- **总分制**：百分制 (0-100分)
- **计算方式**：`（实际得分 / 理论最高分 143分）* 100`
- **题目数量**：10题
- **计分题目**：7题（第4-10题参与计分，第1-3题为企业画像信息，不计入总分）

## 3. 结果判定标准

根据归一化后的最终得分（0-100分），将企业成熟度划分为三个阶段：

| 分数段 | 阶段名称 | 核心特征 |
| :--- | :--- | :--- |
| **0 - 49分** | **初步意识阶段** | • 人力投入被视为单纯成本<br>• 缺乏量化核算与跨部门分析<br>• 决策主要依赖经验 |
| **50 - 79分** | **建设起步阶段** | • 具备一定数据基础<br>• 开始关注ROI但颗粒度不足<br>• 处于定性向定量转型的关键期 |
| **80 - 100分** | **体系化升级阶段** | • 人力资本成为增长引擎<br>• 数据链路全贯通<br>• 具备预测性与高度敏捷性 |

## 4. 计算公式示例

假设用户选择如下：
- Q4: C (20)
- Q5: A (5)
- Q6: B (10)
- Q7: A (20)
- Q8: A, B (2+2=4)
- Q9: B (10)
- Q10: A (20)

**原始总分** = 20 + 5 + 10 + 20 + 4 + 10 + 20 = **89分**
**理论满分** = 143分
**最终得分** = Round((89 / 143) * 100) = **62分**

**判定结果**：62分属于 [50-79] 区间，即 **建设起步阶段**。
