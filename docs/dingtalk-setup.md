# 钉钉通知配置指南

## 1. 创建钉钉机器人

### 步骤一：在钉钉群中添加机器人
1. 打开钉钉群聊
2. 点击右上角的群设置
3. 选择"智能群助手"
4. 点击"添加机器人"
5. 选择"自定义"机器人

### 步骤二：配置机器人
1. 填写机器人名称：`瑞华CMS预约通知`
2. 选择安全设置：
   - **推荐**：选择"加签"方式，系统会生成一个密钥
   - 或者选择"自定义关键词"，填入：`预约`
3. 点击"完成"

### 步骤三：获取配置信息
创建完成后，你会得到：
- **Webhook URL**：类似 `https://oapi.dingtalk.com/robot/send?access_token=xxx`
- **密钥**（如果选择了加签）：类似 `SECxxx`

## 2. 配置环境变量

在 `.env` 文件中更新以下配置：

```bash
# 钉钉通知配置
DINGTALK_WEBHOOK_URL=https://oapi.dingtalk.com/robot/send?access_token=你的access_token
DINGTALK_SECRET=你的密钥（如果使用加签方式）
```

## 3. 重启应用

配置完成后，重启 Node.js 应用：

```bash
npm start
```

## 4. 测试通知

提交一个测试预约，检查钉钉群是否收到通知消息。

## 5. 通知消息格式

系统会发送如下格式的 Markdown 消息：

```markdown
## 🎯 新的预约提交

**姓名：** 张三
**公司：** ABC科技有限公司
**职位：** CEO
**手机：** 13800138000
**问题描述：** 希望了解人力资本价值经营解决方案
**来源页面：** form1.html
**提交时间：** 2025-12-16 16:39:19

> 请及时跟进客户需求！
```

## 6. 故障排查

### 通知发送失败
1. 检查 Webhook URL 是否正确
2. 检查密钥是否正确（如果使用加签）
3. 检查钉钉机器人是否被禁用
4. 查看服务器日志中的错误信息

### 常见错误
- `钉钉 Webhook 未配置，跳过通知发送`：需要配置正确的 Webhook URL
- `签名验证失败`：检查密钥是否正确
- `关键词不匹配`：如果使用关键词验证，确保消息包含设置的关键词

## 7. 安全建议

1. **不要**将 Webhook URL 和密钥提交到代码仓库
2. 定期更换机器人密钥
3. 限制机器人的使用范围
4. 监控机器人的消息发送频率，避免被限流
