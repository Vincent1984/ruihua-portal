📖 使用说明

  1. 等待两个页面完全加载
  2. 点击"滚动到 FAQ"按钮，让两边都显示 FAQ 区域
  3. 仔细对比两边的视觉效果，勾选你发现的差异
  4. 右键点击页面 → 检查元素，对比具体的 CSS 属性
  5. 将勾选的差异项告诉 AI，进行精准修复

💡 提示：按 Ctrl+Shift+C (或 Cmd+Shift+C) 可以快速进入元素检查模式
