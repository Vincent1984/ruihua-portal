🚨 如何彻底清除缓存

  1. Chrome / Edge
    • 按 Ctrl+Shift+Delete (Windows) 或 Cmd+Shift+Delete (Mac)
    • 选择"缓存的图片和文件"
    • 时间范围选择"全部时间"
    • 点击"清除数据"
  2. Safari
    • 按 Cmd+Option+E 清空缓存
    • 或者：Safari 菜单 → 偏好设置 → 高级 → 显示开发菜单
    • 开发 → 清空缓存
  3. Firefox
    • 按 Ctrl+Shift+Delete
    • 勾选"缓存"
    • 点击"立即清除"
  4. 清除缓存后，按 Ctrl+F5 或 Cmd+Shift+R 强制刷新页面
