**行业**：游戏文娱  
**标签**：1000+ 人、研发 · 内容·创意

## 核心指标

| 大模型接入 | 40+ |

## 项目背景

A 股上市游戏公司，研发、发行、美术、策划、运营多岗位并行。模型壁垒、算力分配、跨岗位协作是规模化 AI 的拦路虎。

## 遇到的问题

- ① 各岗位被不同模型工具割裂，算力与协作不通
- ② 研发、发行产能难以倍数级放大

## 希望实现的目标

- ① 全员用上 Agent 工作流，打通模型壁垒
- ② 各岗位产能倍数级放大

## 解决方案

- WorkBuddy+CodeBuddy+TokenHub
- 全员 AI Agent 工作流：打通模型壁垒，研发、发行各岗位产能倍数级放大
- YOOZOO.AI 平台：接入 40+ 大模型，覆盖业务全场景
- 无限量 AI 算力：向全员开放免费工具与 Token
- 配套全岗位培训+ 陪跑

## 带来的结果

- 全员
- Agent 使用
- 无上限
- Token
