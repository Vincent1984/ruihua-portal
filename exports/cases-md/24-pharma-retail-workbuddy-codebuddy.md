# 某医药零售集团 · 用 WorkBuddy+CodeBuddy 把研发与数据链路提效约 50%

**行业**：其他  
**标签**：1000+ 人、研发·IT · 数据分析

## 核心指标

| 整体提效 | ~50% |
| AI 代码采纳率 | 80%+ |
| 员工覆盖率 | 90%+ |
| 知识沉淀 | 100% |

## 项目背景

港股上市的医药零售与在线医疗企业，产品、研发、测试、运维、BI 多条线并行。需求文档靠人写、测试靠人堆、BI 靠人拉——研发与数据链路长，C 端服务还要承接语音/图像找药的多模态交互。

## 遇到的问题

- ① PRD 撰写耗时长，需求调研周期拉满
- ② 测试用例与 BI 分析靠人工，效率天花板明显
- ③ C 端找药场景多模态，传统交互承接不住

## 希望实现的目标

- ① 研发与数据全链路提效
- ② 沉淀自己的知识库，提升 AI 代码采纳率
- ③ 提升 C 端智能服务的响应速度

## 解决方案

- WorkBuddy+CodeBuddy+ 混元大模型
- 需求提炼与 PRD 生成 Agent：PRD 撰写从 3 人日压到 1.5 人日内
- 测试用例自动生成+BI 数据深度分析：测试与 BI 效能各提升约 50%
- C 端智能服务：混元驱动多模态交互（语音/图像/图片找药）
- 配套研发/数据培训+ 陪跑
