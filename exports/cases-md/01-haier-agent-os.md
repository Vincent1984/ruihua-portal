# 海尔智家 · 用 Agent OS 把 AI 能力交到每一位员工手上

**行业**：制造业  
**标签**：1000+ 人、研发 · 运营·供应链 · 数据分析 · 文书

## 核心指标

| 员工自建智能体 | 262 |
| 轻应用 | 5100 |
| 研发型号效率 | ↑20.7% |
| 采购成本 | ↓10% |

## 项目背景

一家横跨海尔/卡萨帝/Leader 多品牌、全球 200+ 国家和地区运营、员工约 13.5 万人的大型家电制造集团。AI 能力停留在少数部门试点，一线员工卡在不会开发的门槛上。

## 遇到的问题

- ① 工艺员把数小时耗在工艺编制上，老师傅经验传不下去
- ② 经营数据靠人拉报表，出了问题层层追问才能定位原因
- ③ 采购靠经验拍板，缺乏量化支撑
- ④ 老图纸躺在档案室，调不出来、用不上

## 希望实现的目标

- ① 工艺员从执行者变审核者，编制时长从数小时压到分钟级
- ② 经营分析自动推送、自动追因，管理层看得见实时全局
- ③ 采购决策有数据支撑、可量化、可复盘

## 解决方案

- 基于 WorkBuddy/腾讯云全栈 AI+ClawPro+ 自研智小能平台，落地企业级 Agent OS
- 智能工艺规划 Agent：工艺员转审核者，编制分钟级
- 经营分析 Agent：每日自动推送经营报告+ 自动追因
- 采购决策 Agent：量化采购经验、结合历史行情辅助理性判断
- 图纸识别 Agent：老图纸 AI 识别→数字化系统
- 全民开发者机制：员工自然语言描述需求，系统自动生成 AI 应用
