# TCL 实业 · 用 CodeBuddy 让研发团队从改不动老代码里解放出来

**行业**：制造业  
**标签**：1000+ 人

## 核心指标

| 研发渗透度 | 90%+ |
| 核心团队覆盖 | 100% |
| 编码效率 | ↑70%+ |
| 问题排查成本 | ↓80%+ |

## 项目背景

全球智能终端头部企业，产品横跨电视、手机、IoT 多端，机型与系统版本庞杂、历史代码沉重。5 年以上的代码无人维护，Android 与 iOS 双端重复劳动。

## 遇到的问题

- ① 5 年以上无人维护的历史代码，谁都不敢改
- ② Android 到 iOS 跨平台迁移靠人工重写，适配周期以周计
- ③ 整机 API Bug 定位修复慢，缺陷藏在深层调用里

## 希望实现的目标

- ① 历史代码敢改、能改，改造工时大幅压缩
- ② 跨端适配从周级压到天级
- ③ 缺陷定位修复效率翻倍

## 解决方案

- 引入腾讯云 CodeBuddy（Agentic 模式），AI 解读历史代码+ 功能改造+ 测试生成
- 跨平台代码迁移 Agent：Android 到 iOS 自动适配，周期从 2 周压到 2 天
- 整机 API Bug 修复 Agent：自动定位深层调用、生成修复（播放卡顿 8h→1.5h）
- 配套研发效能培训+ 陪跑，把 Agent 用法沉淀进团队
