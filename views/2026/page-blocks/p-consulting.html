01

混合员工编制规划

回答一个最基础的问题——某个职能，到底该配几个人、几个 Agent？

企业真实问题

岗位说明书还是「纯人假设」，人和 Agent 的活儿边界模糊：要么互相抢活、要么互相等；AI 已经扛下一半工作量，编制和预算却按人头批。

我们怎么做

从业务场景出发做「任务颗粒度」拆解——把岗位拆成任务，逐项判断由碳基（人）、硅基（Agent）、还是碳硅混合完成；重新划定人机分工边界；据此重构碳硅混合工作流，形成新的混合编制模型：一个岗位 = 多少人力 + 多少硅基产能。

预期交付物
岗位任务拆解与人机分工边界表碳硅混合编制模型核心场景混合工作流图编制切换路线图
可感知的价值

加业务不再默认等于加人；每个团队清楚自己的人力与硅基产能配比；编制从「人头预算」变成「产能预算」。

02

碳硅双轨绩效与激励

让「人 + AI」的产出可衡量、可激励。

企业真实问题

Agent 的产出算谁的？员工用 AI 效率翻倍，绩效表里体现不出来；考核看的还是工时和动作，AI 的贡献不计入——用得好的人没被看见，组织就失去把 Agent 用深的动力。

我们怎么做

建立「碳轨 / 硅轨」双轨度量体系：

  • 碳轨（人）：判断力、协同力、对 Agent 的驾驭与调优贡献
  • 硅轨（Agent）：任务完成率、准确率、单位任务成本、可用性

两轨合并成团队与岗位的混合绩效口径，并配套激励机制：AI 提效成果分享、Agent 调优贡献纳入评价、超级用户认证与荣誉体系。

预期交付物
碳硅双轨指标体系岗位混合绩效方案激励与认可机制设计配套制度文本
可感知的价值

「人 + AI」的产出第一次被完整看见；用 AI 用得好的人被看见、被激励；考核从「看动作」转向「看结果 + 看驾驭力」。

03

人力 + 算力成本管控

成本结构重构，让整体 ROI 可算、可看、可优化。

企业真实问题

人力成本没降下来，算力成本又涨上去——两头花钱，却没人有一本全景账：token 花在哪个场景、值不值、明年预算怎么定，都说不清。

我们怎么做

把成本结构重新拆一遍：人力成本（编制、组织、生态用工）与算力成本（token、平台、私有化运维）统筹进一张账本；按场景建立可行的单位任务成本与 ROI 测算模型；做场景优先级排序——哪些值得投入算力、哪些该收手；配套成本治理规则（预算、配额、告警、审计）。

预期交付物
人力 + 算力成本全景账场景 ROI 测算模型成本治理规则与预算机制成本看板设计
可感知的价值

钱花在哪、值不值，一屏看得见；省钱不是少用，是聪明地用；整体 ROI 从「说不清」变成可追踪、可优化。

04

人机协同机制与流程

从「几个人会用」，到「组织会干」。

企业真实问题

Agent 靠个人自觉在用：没有 SOP、没有效果看板、没有责任人；试点跑通了复制不开，人的使用习惯一变，效果就回退。

我们怎么做

把跑通的试点固化成机制：

  • 人机协同 SOP：谁派活、谁复核、什么节点必须 Human-in-the-loop、出问题谁兜底
  • 效果看板：任务完成率 · 准确率 · 单位成本 · 人效，一套指标看全局
  • 治理节奏：周复盘、月度调优、季度评审，责任到人
  • 组织演进：以「新质组织五维模型」（治理价值观 · 商业模式 · 生产范式 · 管理范式 · 生态战略）为参照，给出组织架构向新质组织平稳演进的路径建议
预期交付物
人机协同 SOP碳硅混合效果看板治理节奏与责任矩阵组织演进路径建议
可感知的价值

试点能复制、机制能自转；组织在不大动干戈的前提下完成机制进化，向「碳硅共智」稳步靠近。
